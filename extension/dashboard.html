Première étape

Choisis le dossier de ta bibliothèque

Chaque scan y sera enregistré automatiquement, avec son analyse, ses références et les commandes Claude Code. Conseil : un dossier dédié sur le disque qui a de la place, par exemple D:\DIP-Library.

  1. Scanne un site avec le panneau DIP : le pack est rangé dans packs/.
  2. Écris son ADN avec Claude Code (/dip-dna), sans clé API.
  3. Dans « Créer », décris ton projet : DIP choisit les références et te donne la commande à coller dans Claude Code.

DIP comporte trois éléments, chacun dans son propre dossier. DIP (D:\DIP) scanne et contrôle, et se met à jour avec une commande. Ta bibliothèque garde tes scans, tes effets et tes sites ; DIP ne l’écrase jamais. Claude Code, ouvert dans la bibliothèque, crée et construit.

01

Installer et mettre à jour

PowerShell, une seule fois puis à chaque nouvelle version (un bandeau te prévient) :

Première fois : chrome://extensions → Mode développeur → Charger l’extension non empaquetée → D:\DIP\extension. Ensuite : commande, puis « Recharger DIP ». Les commandes /dip-*, les skills et les règles de ta bibliothèque se mettent à jour toutes seules.

02

Collecter

Un site : icône DIP → mode Deep → « Disséquer ce site ». Plusieurs sites : page Collecte, une adresse par ligne. Vise 20 sites variés ou plus, puis corrige secteur et style dans la fiche de chaque site.

03

Écrire les ADN

Terminal dans le dossier de la bibliothèque → claude → /dip-dna. Claude écrit l’essence de chaque site (badge ADN).

04

Comprendre une animation

Panneau DIP → « Analyser une animation précise » → Entourer → dessine un cercle. Puis Effets → la carte → copie /dip-effect … dans Claude Code : nom, recherche web, recette exacte, démo.

05

Créer

Page Créer : décris le projet, garde les références proposées, copie la commande dans Claude Code. Le site se construit dans sites/<projet> avec la richesse minimale : 10 sections, 12 visuels, 3 moments signature et des appels à l’action réguliers.

06

Contrôler

/dip-review sites/<projet> : revue, corrections, nouveau passage ; les erreurs vont dans LESSONS.md pour ne plus se répéter. Objectif ≥ 85, suivi dans Sites.
